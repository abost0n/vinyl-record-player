## Description

The Interactive Vinyl Record Player is a Python-based digital media application created using the pygame library. The project simulates a realistic vinyl record player where users can upload and play their own music files while interacting with animated visual elements inspired by a real turntable.

This project combines digital art, animation, audio playback, and user interaction into one multimedia experience. Users can upload their own songs, upload album artwork, control volume, play and pause music, and interact with the vinyl record using a scratch effect that allows the record to rotate through mouse dragging.

The goal of the project was to create a visually creative, fun, and interactive media application that demonstrates the use of Python for digital arts and entertainment.

## Design & Development Process

One of the main challenges during development was synchronizing the vinyl animation with the music playback while also creating smooth interactive controls. Another challenge was implementing the scratch interaction effect using mouse movement and rotational calculations.

The project required learning how to:
- handle file uploads,
- edit photos,
- play audio dynamically,
- create animations using pygame,
- rotate graphical objects,
- process mouse interaction,
- and create custom graphical interfaces.

The visual design of the vinyl player was inspired by classic record players, my love for music, and the record player option that instagram has.
